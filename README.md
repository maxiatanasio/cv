# Maximiliano Atanasio — Portfolio

Static, responsive portfolio. No build step, API keys or environment variables required.

## Deploy to Vercel

1. Unzip this folder.
2. Push its contents to a new GitHub repository.
3. In Vercel choose **Add New → Project**, import the repository.
4. Select **Other** as the framework preset; leave build command empty and output directory at project root.
5. Click **Deploy**.

Alternatively, from this folder with the Vercel CLI installed, run `npx vercel` and follow the prompts.

## Customize

- Edit text and links in `index.html`.
- Edit colors and layout in `styles.css`.
- Replace `assets/portrait.png` with your preferred photo.
